Fake News Detection Using Machine Learning

This project detects fake and real news using machine learning techniques.
It is built using Python and Flask.

 Features
- Fake vs Real news prediction
- Machine Learning model using TF-IDF
- Simple web interface with HTML & CSS

Technologies Used
- Python
- Flask
- Machine Learning
- HTML, CSS
- random forest
- naive bayes
- logistic regression

 How to Run
1. Install required libraries
2. Run app.py
3. Open browser and go to http://127.0.0.1:5000/
